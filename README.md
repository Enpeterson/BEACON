# BEACON

**Bayesian Estimation and Correction for AI/AN Outcomes using Native-data**

This repository contains reproducible demo scripts for statistical methods developed in collaboration with Tribal Nations. Because all projects involve Tribal health data governed by data use agreements, original data cannot be shared publicly. Each project folder contains a self-contained demo script that replicates the analysis using synthetic data generated to mirror the structure of the real data.

## Projects

| Folder | Description |
|--------|-------------|
| [GDM-Oklahoma](GDM-Oklahoma/) | Bayesian spatial model for adjusted AI/AN gestational diabetes prevalence in Oklahoma, integrating Cherokee Nation clinical data with OSDH surveillance data |

## Data Governance

All original data used in these analyses are governed by Tribal data use agreements. To inquire about data access, contact the relevant Tribal Nation directly:

- **Cherokee Nation Public Health**: [cherokee.org/services/health](https://www.cherokee.org/services/health)
